3. Порядок и условия обработки

3.1. Обработка осуществляется смешанным способом — с использованием средств автоматизации и без их использования. С персональными данными совершаются следующие действия: сбор, систематизация, хранение, изменение, использование, обезличивание, блокирование, предоставление уполномоченным лицам, удаление.

3.2. Оператор не принимает решений, порождающих юридические последствия для субъекта, исключительно на основании автоматизированной обработки его персональных данных.

3.3. Оператор не продаёт персональные данные, не передаёт их третьим лицам для рекламы и не использует для рассылок без отдельного согласия.

3.4. Доступ к персональным данным имеют только работники Оператора, которым он необходим для выполнения трудовых обязанностей, и уполномоченные лица, указанные в разделе 4.

3.5. Для защиты персональных данных Оператор принимает правовые, организационные и технические меры, предусмотренные статьёй 17 Закона, в том числе:

  • назначает лицо, ответственное за осуществление внутреннего контроля за обработкой персональных данных;
  • утверждает локальные акты по вопросам обработки персональных данных и знакомит с ними работников;
  • ограничивает доступ к персональным данным кругом лиц, которым он необходим;
  • передаёт данные с Сайта только по защищённому протоколу HTTPS;
  • хранит заявки в рабочих учётных записях, защищённых паролем и доступных только уполномоченным работникам.

6.1. Сайт сам не устанавливает cookie-файлы и не использует системы веб-аналитики и рекламные счётчики.
